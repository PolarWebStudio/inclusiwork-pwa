
# 🤝 InclusiWork - PWA de Microtareas y Gestión de Ingresos

InclusiWork es una aplicación web progresiva (PWA) orientada a la inclusión laboral, diseñada para facilitar la ejecución de microtareas accesibles y la gestión de saldos y retiros locales.

## 🚀 Características
- **Módulos de Tareas:** Clasificación de imágenes/audios, encuestas rápidas y validación de empresas locales.
- **Gestión de Saldo:** Visualización de saldo disponible en COP y pasarela para retiros (Nequi, Daviplata, Binance Pay).
- **Accesibilidad:** Diseñada con estándares de contraste e integración para lectores de pantalla.
- **Modo PWA:** Arquitectura lista para instalación offline.

## 🛠️ Tecnologías utilizadas
- HTML5 semántico
- CSS3 (Variables, Flexbox, Grid)
- JavaScript Vanilla (Módulos de lógica y tareas)
